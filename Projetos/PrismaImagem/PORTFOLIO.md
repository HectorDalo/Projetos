# PrismaImagem — apresentação para portfólio

Aplicativo desktop de IA para gerar e editar imagens, com interface nativa em C# e API própria em Node.js. Integra processamento local com ComfyUI/Stable Diffusion, remoção de fundo em Python e OpenAI opcional.

O trabalho reúne arquitetura de software, integração de modelos de visão computacional, proteção de credenciais no Windows e testes automatizados de API. Inclui workflows para geração, edição por referência, ampliação Full HD, recorte transparente e reconstrução de área selecionada.

**Tecnologias:** C#, .NET Framework, Windows Forms, Node.js, Python, ComfyUI, Stable Diffusion, rembg, ONNX Runtime e Windows DPAPI.

**Papel do projeto:** desenvolvimento da aplicação e integração de modelos existentes; não treinamento de um modelo proprietário. Os testes automatizados verificam contratos e fluxos, sem representar um benchmark de qualidade visual.
